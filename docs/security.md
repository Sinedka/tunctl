# Модель доверия

Группа vpnctl даёт доступ к Unix socket с режимом 0660. Обработчик дополнительно проверяет UID через SO_PEERCRED и список операторов из root-owned конфигурации. Удаление пользователя из системной политики отзывает разрешение для следующих запросов. Операторы являются доверенными администраторами VPN-соединения всего хоста. Они могут выбрать собственный VPN endpoint, импортировать профиль, остановить соединение и читать эксплуатационные метаданные.

Только `policyUser` может менять пользовательский слой маршрутизации. Это явное полномочие добавлять обходы VPN для всего хоста, в том числе широкие CIDR. Системные DNS-ограничения и kill switch задаёт администратор. Для запрета делегирования оставьте policyUser равным null. Правила приложений применяются внутри slice делегированного UID. Пользователь с таким правом может запустить в ней любую свою программу. Маршрутизация приложения не служит средством изоляции враждебных процессов одного UID.

Профили хранятся в `/var/lib/vpnctl/profiles` с режимом 0600 и закрытым родительским каталогом. Приватные ключи передаются через локальный socket и попадают в runtime-файл OpenVPN в каталоге с режимом 0700. Backend записывает в журнал операций имена и результаты переключений. Закрытые ключи и содержимое профиля в ответ status не включаются.

Импортёр читает только профили и необходимые относительные файлы. Архив обрабатывается без распаковки. Ограничены размер записей, распакованный объём, размер кадра, число файлов и профилей. Ссылки, абсолютные имена и traversal в ZIP отвергаются. Backend принимает подмножество клиентских директив и пересобирает конфигурацию. Директивы внешних команд, plugin, вложенного config, management, изменения журналов и путей к файлам запрещены. Интеграции с сертификатами и аккаунтами, которым нужны такие директивы, потребуют отдельной реализации.

Системные команды запускаются с фиксированными именами и аргументами через exec. Наборы nftables формируются из проверенных IP, действий и допустимых имён slice. На management socket OpenVPN имеет доступ только root. Передача control socket пользователю вне списка операторов сама по себе не даёт ему права выполнить операцию.

Nix-модули принимают настройки и пути к программам. Содержимое закрытых ключей, пароли, auth-файлы и архивы должны находиться вне Git и исходного дерева, передаваемого через `path:`. SHA-256 помогает выявить повреждение сохранённого профиля. Доверие к издателю файла, администраторам машины и указанному в профиле центру сертификации остаётся обязательным.
