# Устройство приложения

`vpnctl-core` содержит схему IPC, проверку адресов, DNS-имён и профилей, разбор RTT и потерь. В `src/linux.cpp` находятся Unix socket, запуск утилит с массивом аргументов, ограничение времени, атомарная запись и преобразование правил в nftables. Клиент использует FTXUI 7 для полноэкранного интерфейса, обработки событий, выбора файлов в терминале и ввода текста.

`vpnctl` выполняет диагностику с правами пользователя. Импортёр на Python читает ZIP и внешние файлы в том же контексте. Протокол передаёт содержимое профиля. Привилегированный обработчик принимает только именованные операции и проверяет данные повторно.

`vpnctl.socket` принимает подключения на `/run/vpnctl/control.sock`. Для каждого подключения systemd запускает экземпляр `vpnctl@.service` с сокетом на stdin. Один запрос и один ответ содержат четырёхбайтовую длину в сетевом порядке и JSON в UTF-8. Лимит кадра — 2 МиБ. Обработчики сериализуют изменения через flock. Команды OpenVPN выполняются отдельным `vpnctl-tunnel.service`.

При переключении backend фиксирует факт предыдущего подключения в /run, останавливает клиент и создаёт временную ссылку на кандидата. Сервис проверяет SHA-256, получает числовые адреса endpoint и запускает OpenVPN. После systemd READY, установки маршрутов, проверки интерфейса и состояния CONNECTED,SUCCESS через management socket backend атомарно меняет постоянную ссылку. Ошибка кандидата возвращает предыдущий профиль и повторно запускает его, если соединение было активно. Таймер подбирает прерванную транзакцию. После перезагрузки автозапуск использует последний подтверждённый профиль.

`vpnctl-session.service` сохраняет выходной фильтр между остановкой и запуском клиента. Перезапуск OpenVPN инициирует systemd. Таймер повторно сопоставляет динамические cgroups, изменения шлюза подхватываются ядром из main. Диагностика состояния отдельно опрашивает OpenVPN, в том числе во время переподключения.

| Каталог | Назначение |
|---|---|
| `src/`, `include/vpnctl/` | C++23-клиент, backend, ядро и Linux API |
| `src/import.py`, `src/prepare.py`, `src/dns.py` | Обработка архивов, подготовка transport endpoint, DNS upstream с TTL |
| `nix/modules/` | Системная политика и пользовательская конфигурация |
| `nix/tests/`, `tests/` | Изолированный сервер в VM, namespace, тесты C++ и Python |
| `examples/` | Подключение обоих модулей в существующую конфигурацию |

Описание параметров OpenVPN и механизма socket cgroupv2 приведено в первичной документации. [OpenVPN 2.6](https://build.openvpn.net/man/openvpn-2.6/openvpn.8.html) · [nftables](https://www.netfilter.org/projects/nftables/manpage.html)
